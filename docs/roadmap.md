# 路线图

里程碑按能力划分。本仓库当前提交的是 M0 脚手架：契约和示例可以校验，同时为后面的里程碑留了可运行的空壳。空壳不等于该里程碑已经完成。

## M0 契约

定下契约格式和对象，包括 Action 和 EvalCase。JSON Schema 为校验真源，YAML 为编写格式。内核能加载、校验、diff 和应用补丁。示例 Namespace（假期）用来证明这条链路是通的。

## M1 MCP 读工具与评测骨架

对外提供 MCP 读工具：列出 Namespace、按 id 取对象、搜索目录。评测命令能跑黄金用例。M0 脚手架里这两项已经能对示例目录运行，但打分只检查对象是否还在，读工具也只服务于这份本地模型。

## M2 Harness 推导动作并生成评测用例

harness 按 `docs/harness-flow.md` 工作：读材料、提问、推导对象和 Action，证据不够就写 GapLog 并回到业务侧，最后生成 EvalCase。本里程碑尚未开始。

## M3 合并前回归与工作台评测视图

拉取请求上的回归成为正式门禁，工作台的评测页展示用例结果。M0 的 CI 已经调用占位评测，工作台评测页仍是说明文字。

## M4 编译到已有引擎

把指标编译到已有引擎，导出 OSI，并开放 MCP 写工具。写工具按 Action 的审批要求做写回。M0 只有编译器接口、OSI 导出接口，以及总是返回未实现的写工具。
